# Hamara Guest House

Website resmi Hamara Guest House di Pugung Walur, Krui, Lampung Barat.

## Menjalankan secara lokal

**Persyaratan:** Node.js

1. Pasang dependensi:
   ```bash
   npm install
   ```
2. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
3. Buat build untuk produksi:
   ```bash
   npm run build
   ```
